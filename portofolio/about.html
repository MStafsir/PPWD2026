Profil Singkat

Saya adalah seorang mahasiswa Sistem Informasi yang memiliki minat mendalam pada pengembangan web, perancangan antarmuka pengguna (UI/UX), dan sistem informasi interaktif.

Fokus utama saya adalah membangun aplikasi web yang berkinerja tinggi, mudah diakses oleh semua pengguna (aksesibilitas), dan memiliki estetika visual yang tertata rapi serta berkarakter.

Keahlian & Teknologi

Teknologi yang sering saya gunakan dalam pengerjaan tugas dan proyek:

  • Frontend: HTML5 Semantik, CSS Modern, JavaScript (ES6+), WebGL Shader
  • Backend: PHP, MySQL / MariaDB
  • Tools: Git, GitHub, Laragon, VS Code
